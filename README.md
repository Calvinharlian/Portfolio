# Calvin's portfolio

React, Vite, Tailwind CSS, and Framer Motion.

```bash
npm install
npm run dev
```

- Edit all copy, links, photo, and CV path in `src/data/content.js`.
- Put a real photo and `calvin-cv.pdf` in `public/`, then set `photo` and `cvUrl`.
- Update the domain in `index.html` after deploying.
- Deploy on Vercel or Netlify: build command `npm run build`, output folder `dist`.
